# Notes App

Simple notes app with search and local persistence.

## Features
- Create / update / delete notes
- Search by title or body
- Autosave to localStorage

## Limitations
- No folders or rich editor
- Single device only

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- localStorage persistence

## Run
```bash
npm install
npm run dev
```
